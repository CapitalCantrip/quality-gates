Problem. ADR-001 says both gates must count CC the same way, but Python counting is implemented twice, so the guarantee lives in two places that can drift.

Solution. Deepen lizard_scan into a complexity scan module that also hides radon behind the same interface. Both gates call it and only add their own threshold or coverage logic.

  • ADR-001's "same counter" is enforced in one place
  • Baseline keys agree across gates
  • Tests: one fixture per language
  • Deletes the radon subprocess path in crap
Supports ADR-001 rather than contradicting it.

Problem. Each language is spread across eight places in a 686-line file, and its coverage loader returns a different shape, so adding one (Rust is next in line) is shotgun surgery.

Solution. Every coverage reader satisfies one interface — load a report, answer "coverage of this function" — and crap scores every language through one path.

  • Three adapters: a real seam
  • One scoring path, tested once
  • Adapters tested with fixture reports
  • New language = one adapter + one row

3 · Leaf modules raise; only the CLI exits

Worth exploring in-process
  • istanbul.py · lizard_scan.py · crap.py · quality_check.py (25 × sys.exit(2))
Before
After

Problem. Reader modules print and exit themselves, so their interface includes "may kill the process", tests must catch SystemExit, and a shared reader like istanbul hard-codes the [crap] tag.

Solution. Leaves raise one error type; each gate's main maps it to its tag and exit 2. Fits naturally inside candidates 1 and 2.

  • Readers reusable by either gate
  • Tests assert on errors, not exits
  • Exit codes owned in one place

Problem. The baseline rule ("fail on new or worse, and on paid debt not yet recorded") is implemented twice; comment-debt's copy predates ratchet.py.

Solution. comment-debt feeds per-file counts into ratchet.enforce, keeping only its line-number detail and the "GONE" case as a small extension.

  • One definition of Baseline
  • Same messages across three gates

Speculative: comment-debt's file-keyed, line-detailed messages differ enough that the shared interface may need widening, which could cost more depth than it gains. It works and rarely changes.
