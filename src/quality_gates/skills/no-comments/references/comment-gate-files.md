# Comment gate files

Generated by `qg-references` from docs/adr/what-gets-scored.md, section "The comment gate's files", in the quality-gates repo. To change this rule, edit that section and rerun `qg-references`.

**The comment gate's files** are the files in scope less
`settings.no-comments.exclude` in `quality-gates.json`, which matches whole
path segments as `exclude` does. `comment-debt` checks a language only when
that language's comment component is chosen in the choice file: `no-comments`
for Python, `no-comments-rust` for Rust. Without a choice file it checks Python
only. It has no `--exclude` flag. A file it cannot read, because it does not
parse or is not UTF-8, is unmeasured: the gate names it and fails, keeps any
baseline entry it has and records none for it.
